)

Evaluates the values of a scalar field at remote points of the domain from the mapping, the DoF handler and the solution field.

Template Parameters
dimDenotes the number of spatial dimensions.
VectorTypeVector type of the solution vector.
Parameters
[in]mappingMapping of the domain.
[in]dof_handlerDoF handler associated to the solution field.
[in]solution_fieldVector containing the solution field. For distributed meshes, ghost elements must be updated.
[in]evaluation_pointsVector of points where the values of the solution field are to be evaluated.
[in,out]remote_point_evaluatorUtilities::MPI::RemotePointEvaluation object used to evaluate values of the variable of interest at given points of the domain.
[in,out]evaluated_scalar_valuesVector of evaluated scalar values.
[in]first_selected_componentFirst component of the solution to select if the solution field is a vector field. This is used to extract the correct field when the solution vector contains multiple fields (e.g., velocity and pressure are stored in a same solution vector).
Remarks
If a given evaluation point is not within the simulated domain, an exception is thrown.
