55 /**
56 * @brief Different transformation function types for the signed distance:
57 * - tanh: hyperbolic tangent
58 * - piecewise_polynomial: 4th degree piecewise polynomial. The latter takes
59 * the following form:
60 *
61 * if \f$d < 0 \f$
62 * \f$\phi = 0.5 - 0.5(4d' + 6d'^2 + 4*d'^3 + d'^4)\f$
63 *
64 * else
65 * \f$\phi = 0.5 - 0.5(4d' - 6d'^2 + 4*d'^3 - d'^4)\f$
66 *
67 * with \f$d' = d/d_\mathrm{max}\f$, where \f$\phi\f$ is the phase
68 * fraction, \f$d\f$ the signed distance and \f$d_\mathrm{max}\f$ the
69 * maximum redistanciation distance. This transformation clamps the phase
70 * fraction to 0 or 1 when \f$d = \pm d_\mathrm{max}\f$.
71 */
72 enum class RedistanciationTransformationType : std::int8_t
73 {
74 tanh,
75 piecewise_polynomial
76 };

125 /**
126 * @brief Type of electromagnetic scaling to apply to the solution of the time-harmonic Maxwell solver after solving the linear system. This is relevant when the user wants to recover the physical solution in dimensional units from the dimensionless solution.
127 * - none: no scaling will be applied to the solution after solving the linear
128 * system, so the solution will be in dimensionless units.
129 * - electric_field: the solution will be scaled by the electric scaling
130 * factor given from the user input parameter. This factor needs to match the

139 * or magnetic field Dirichlet boundary conditions, those need to be scaled
140 * accordingly.

144 none,

150 /**
151 * @brief Parameters for the time coupling strategy of the time-harmonic Maxwell solver with the other physics solvers.
152 * - none: the time-harmonic Maxwell solver will only be solved at the first
153 * iteration of the time integration and will not be solved in the subsequent
154 * iterations.
155 * - iteration: the time-harmonic Maxwell solver will be solved every N time
156 * iterations, where N is given by the user input parameter "coupling
157 * iteration".
158 * - time: the time-harmonic Maxwell solver will be solved when crossing a
159 * time multiple, e.g. every T seconds, where the time multiple is given by
160 * the user input parameter "coupling time".
161 * - threshold: the time-harmonic Maxwell solver will be solved when the
162 * maximum change in the material properties of the problem change beyond a
163 * certain threshold, where the threshold value is given by the user input
164 * parameter "coupling threshold".
165 */
166 enum class TimeHarmonicMaxwellCouplingStrategy : std::int8_t
167 {
168 none,
169 iteration,
170 time,
171 threshold
172 };

720 * "scalars" subsection. The moments are not given one by one: they are the
721 * moments of a particle size distribution, defined in the "distribution"
722 * subsection by its family and by a list of expressions whose first entry is
723 * the number density, in particles per m^3, followed by the parameters of
724 * the family.
725 *
726 * The number of scalars is not known when the parameters are declared. The
727 * number of components of the scalars function is therefore the number of
728 * expressions given, and the QMOM physics verifies that it matches the

730 * the number of scalars is 0.

744 /// the particle size distribution. Ignored if the distribution type is
745 /// none.

789 /// Number of scalars transported together with the moments

791
792 /// Names of the scalars, used for the output. scalar_0, scalar_1, ... if
793 /// they are not given in the parameter file.
794 std::vector<std::string> scalar_names;
795
796 /// Number of transported moments M_0 to M_{number_of_moments - 1}
797 unsigned int number_of_moments = 4;
798
799 /// Number of nodes of the quadrature that uses all the transported
800 /// moments. N nodes are defined by 2N moments, so an odd number of moments
801 /// requires one more node. It is computed from number_of_moments when the
802 /// parameters are parsed.
803 unsigned int number_of_nodes = (number_of_moments + 1) / 2;
804
805 /// Operator splitting scheme between the physical-space transport and
806 /// the phase-space evolution
807 QMOMSplittingScheme splitting_scheme = QMOMSplittingScheme::lie;
808
809 /// Include the nucleation source
810 bool enable_nucleation = false;
