Detailed Description

template<int spacedim>
class BackgroundCellsSearchTree< spacedim >

R-tree of the locally owned cells of a background triangulation, used to find the background cells to which the cells of a solid object are mapped.

Each locally owned background cell is represented by the cube centered on its center whose half-width is its diameter. The tree depends only on the background triangulation, so it is shared by all the solid objects and needs to be rebuilt only when the background triangulation changes (repartition, refinement or motion of the grid).

Template Parameters
spacedimSpatial dimension of the background triangulation.
