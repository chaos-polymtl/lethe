Detailed Description

template<int dim>
class QMOMFieldFunction< dim >

Function of all the QMOM fields, built from the functions of the scalars and from the particle size distribution.

It has one component per field, n_scalars + n_moments components in total. The scalars come first, then the moments:

  • components 0 to n_scalars - 1 are the scalars: component c is scalar c;
  • components n_scalars to n_scalars + n_moments - 1 are the moments: component c is the moment M_k, with k = c - n_scalars.

For example, with 2 scalars and 4 moments, components 0 and 1 are the scalars 0 and 1, and components 2, 3, 4 and 5 are the moments M_0, M_1, M_2 and M_3. Without scalars, component c is the moment M_c.

Scalar c is given by expression c of the scalars function, so the scalar expressions must be given in the same order as the scalar names.

The moments are the raw moments of the particle size distribution, scaled by the number density: M_k = n E[L^k], where n is the number density in particles per m^3 and L the particle size in m. They are computed analytically by QMOMKit, and are all zero if the distribution type is none.
