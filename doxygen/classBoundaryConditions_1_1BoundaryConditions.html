Detailed Description

This class is the base class for all boundary conditions. It stores the general information that all boundary condition share. In Lethe, boundary conditions are identified with an id, a type and, in the special case of periodic boundary condition, a periodic matching id (periodic_id) and a periodic direction (0, 1 or 2).
