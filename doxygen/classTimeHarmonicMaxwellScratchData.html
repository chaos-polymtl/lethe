Detailed Description

template<int dim>
class TimeHarmonicMaxwellScratchData< dim >

Class that stores the information required by the assembly of the Discontinuous Petrov-Galerkin (DPG) ultraweak formulation of the time-harmonic Maxwell equations. For each cell, it evaluates the base functions of the test space ( \(\mathbf{F}\) and \(\mathbf{I}\)) with their curls, the base functions of the interior trial space ( \(\mathbf{E}\) and \(\mathbf{H}\)) and the effective material properties at the quadrature points. Additionally, for each face of the cell, it evaluates the base functions of the tangential traces of the test space and the base functions of the skeleton trial space ( \(\hat{\mathbf{E}}\) and \(\hat{\mathbf{H}}\)), with their cross products with the normal. Since the Nedelec base functions whose degrees of freedom are not located on a face have a zero tangential trace on this face, only the base functions associated with the face are evaluated.

Template Parameters
dimAn integer that denotes the number of spatial dimensions. Only dim = 3 is supported.
