unsigned int Parameters::QMOM::number_of_nodes = (number_of_moments + 1) / 2

Number of nodes of the quadrature that uses all the transported moments. N nodes are defined by 2N moments, so an odd number of moments requires one more node. It is computed from number_of_moments when the parameters are parsed.
