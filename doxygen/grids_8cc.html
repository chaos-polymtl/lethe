static void warn_if_scaling_curved_manifolds ( const Parameters::Mesh &  mesh_parameters,
const Triangulation< dim, spacedim > &  triangulation 
)
static

Warn when a mesh scaling factor is applied to a grid which carries curved manifolds.

Meshes generated by deal.II (type = dealii) or by Lethe's built-in generators (type = lethe) may carry curved manifolds attached to the triangulation. GridTools::scale moves the vertices but does not scale their attached manifolds, so a scale factor other than 1 can leave the manifolds inconsistent with the mesh and distort curved geometries under refinement. The scaling is still applied, but the user is warned so that the resulting mesh can be checked; such geometries can alternatively be scaled through the grid arguments.

Grids whose cells and faces all use the flat manifold, such as the hyper_cube or hyper_rectangle grids commonly used to delimit a mesh refinement box, are invariant under scaling and do not trigger the warning. Neither do gmsh meshes, which carry no manifold.

Parameters
[in]mesh_parametersThe mesh parameters used to generate the grid
[in]triangulationThe triangulation the grid was attached to. It must already carry its manifold ids, hence the check is made after the grid generation.
