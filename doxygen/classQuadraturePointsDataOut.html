Detailed Description

template<int dim>
class QuadraturePointsDataOut< dim >

Build point patches located at quadrature points for visualization, for example to display the QCM filter spheres centered at each quadrature point. Each quadrature point stores its filter radius, filter diameter and the global active index of the cell it belongs to.

Template Parameters
dimAn integer that denotes the number of spatial dimensions.

Build one point patch per quadrature point of every locally owned cell. Each patch stores the filter radius, the filter diameter and the global active index of the cell that owns the quadrature point.

Parameters
[in]dof_handlerDoFHandler whose active cells are traversed.
[in]mappingMapping used to compute the quadrature point locations.
[in]quadratureQuadrature rule defining the points in each cell.
[in]filter_radiusFunction returning the filter radius of a cell.
