Detailed Description

Class responsible for storing the local system of an ultraweak Discontinuous Petrov-Galerkin (DPG) discretization. The assemblers fill the uncondensed local system: the Gram matrix of the test space \(G\), the matrices of the bilinear form in the cell interior \(B\) and on the skeleton \(\hat{B}\), and the load vector \(l\). The solver then condenses this system on the skeleton unknowns using the operators \(M_1 = B^\dagger G^{-1} B\), \(M_2 = B^\dagger G^{-1} \hat{B}\), \(M_3 = \hat{B}^\dagger G^{-1} *\hat{B}\), and the vectors \(M_4 l = B^\dagger G^{-1} l\) and \(M_5 l = *\hat{B}^\dagger G^{-1} l\), and stores either the condensed skeleton system (assembly) or the reconstructed interior solution (interior reconstruction).
