Detailed Description

Class responsible for storing the local system of an ultraweak Discontinuous Petrov-Galerkin (DPG) discretization. The assemblers fill the uncondensed local system: the Gram matrix of the test space \(G\), the matrices of the bilinear form in the cell interior \(B\) and on the skeleton \(\hat{B}\), and the load vector \(l\). The solver then condenses this system on the skeleton unknowns using the operators \(M_1 = B^\dagger G^{-1} B\), \(M_2 = B^\dagger G^{-1} \hat{B}\), \(M_3 = \hat{B}^\dagger G^{-1} \hat{B}\), \(M_4 = B^\dagger G^{-1}\) and \(M_5 = \hat{B}^\dagger G^{-1}\), and stores either the condensed skeleton system (assembly) or the reconstructed interior solution (interior reconstruction).
