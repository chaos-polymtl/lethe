Detailed Description

template<int dim, int spacedim>
class GridPipeAndWaveguide< dim, spacedim >

Generates a 3D mesh of a waveguide embedded in a cylindrical cavity in which a liquid flows.

The geometry consists of three sections joined along the z-axis:

  • A bottom cylinder
  • A central cylinder into which the rectangular-based waveguide is embedded
  • A top cylinder

Note that the mesh of the cylinder is inspired from the hyper_ball function of the deal.II library.

Boundary IDs are assigned as follows: -0: Microwaves (MW) inlet -1: Fluid flow inlet (bottom surface of the cylinder) -2: Fluid flow outlet (top surface of the cylinder) -3: Walls

Material IDs are assigned as follows: -0: Fluid in the channel (cylinder) -1: Air in the waveguide (paving stone)

A CylindricalManifold is attached to the curved lateral surfaces of the cylinder so that mesh refinement preserves the shape of the fluid channel.

Template Parameters
dimThe dimension of the mesh, must be 3.
spacedimThe dimension of the space, must be 3.

The function detailed_circle is a tool used in the core of the file.

This function is an extension of the 2D part of the hyper_ball in-built deal.ii function.

Since the deal.ii merge function needs the two trangulations to have overlapped points, we needed to produce a coarse circular mesh with two points at the exact place where the rectangle would fit. This is why this function was created.

There are three main differences between hyper_ball and detailed_circle:

-Fourteen points were added to the mesh (8 points in the original one) to link the circle with the rectangle we want to merge and to prevent triangular cells from being generated.

  • A central rectangle of width equal to the waveguide width crosses the circle along the x-axis. This minimizes the aspect ratio of the cells contained within the central rectangle because their shape stay nearly rectangular.
  • In the original function, a square lies in the center of the circle. An argument has been added to this function to chose between a square and a circle. We call this shape the "inner shape" of the circle.
