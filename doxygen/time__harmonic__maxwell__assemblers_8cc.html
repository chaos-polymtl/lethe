Compute the incident electromagnetic fields of a rectangular waveguide port from the input parameters. It is only implemented for 3D problems.

Template Parameters
dimSpatial dimension.
Parameters
[in]time_harmonic_maxwell_parametersParameters of the time-harmonic Maxwell physics, which contain the waveguide port definitions.
[in]pPosition where the incident fields are computed.
[in]normalUnit normal vector of the waveguide port face.
[in]effective_electric_permittivityEffective electric permittivity at the point p.
[in]effective_magnetic_permeabilityEffective magnetic permeability at the point p.
[in]waveguide_port_indexIndex of the waveguide port condition within the waveguide port parameters.
Returns
This function returns a std::pair containing the electric field Tensor<1, dim, std::complex<double>> and the magnetic field Tensor<1, dim, std::complex<double>> computed at the given position.
