## [Master] - 2026/09/11

### Changed

- MINOR The members of the `Parameters::*` structs (across `parameters.h`, `parameters_multiphysics.h`, `parameters_cfd_dem.h`, `parameters_lagrangian.h`, and the solver-specific `initial_conditions.h`/`analytical_solutions.h`/`source_terms.h`) now have an in-class default value equal to what they already received via `declare_parameters()`, and `declare_parameters()` derives its `.prm` default string from that same member instead of a second, separately hand-maintained string literal. Entries declared once per instance (e.g. per particle type, wall, boundary condition, constraint, probe or waveguide inlet) keep their literal defaults and are stored in containers filled by `parse_parameters()`. Apart from the fixes listed below, this does not change how any existing `.prm` file is parsed; it makes default-constructed `Parameters::*` objects usable directly (e.g. in unit tests) without hand-setting every field first, and reduces the risk of the struct default and the `.prm` default silently drifting apart. [#2131](https://github.com/chaos-polymtl/lethe/pull/2131/)

### Removed

- MINOR Removed parameters and enumerations that were declared but never used: the `insertion plane threshold distance` parameter of the `insertion info` subsection, the `convective flux name` and `nitsche flux name` parameters of the `post-processing` subsection, the unused `SimulationControl::LagrangianTimeSteppingMethod` enumeration and the never-read `Laser::BeamOrientation` enumeration. None of them had any effect on the simulation. [#2131](https://github.com/chaos-polymtl/lethe/pull/2131/)

### Fixed

- MINOR Fixed a latent null-pointer dereference in `IBParticles<dim>::declare_parameters()`: the `f_gravity` parsed function was only constructed in `parse_parameters()` but was already dereferenced earlier, in `declare_parameters()`. Giving `f_gravity` a default value (as part of the change above) fixes this. [#2131](https://github.com/chaos-polymtl/lethe/pull/2131/)

- MINOR Fixed members of `Parameters::Laser` that were left uninitialized until `parse_parameters()` was called (beam orientation coordinate, direction, axis and rotation axis). [#2131](https://github.com/chaos-polymtl/lethe/pull/2131/)

- MINOR Fixed the parsing of the `particle ray tracing` subsection: the `photon angular offset prn seed` parameter was never read (the angular offset used the `photon insertion prn seed` instead), and the size of the `number of inserted photons per direction` list was not validated. Results only change when the `photon maximum angular offset` is non-zero and the two seeds differ, which is also the case when both are left at their default values. [#2131](https://github.com/chaos-polymtl/lethe/pull/2131/)

### Documentation

- MINOR Fixed the help texts of several parameters, which were copy-pasted from other parameters (e.g. `torque name`, `restart`, `beta threshold`, the floating wall `normal vector`) or had words merged because of missing spaces between concatenated strings. [#2131](https://github.com/chaos-polymtl/lethe/pull/2131/)
