## [Master] - 2026/09/11

### Changed

- MINOR Every member of every `Parameters::*` struct (across `parameters.h`, `parameters_multiphysics.h`, `parameters_cfd_dem.h`, `parameters_lagrangian.h`, and the solver-specific `initial_conditions.h`/`analytical_solutions.h`/`source_terms.h`) now has an in-class default value equal to what it already received via `declare_parameters()`, and `declare_parameters()` derives its `.prm` default string from that same member instead of a second, separately hand-maintained string literal. This does not change how any existing `.prm` file is parsed; it makes default-constructed `Parameters::*` objects usable directly (e.g. in unit tests) without hand-setting every field first, and reduces the risk of the struct default and the `.prm` default silently drifting apart. `tests/core/parameters_defaults_roundtrip` locks this coupling in for a representative subset of structs. [#PR](link)

### Fixed

- MINOR Fixed a latent null-pointer dereference in `IBParticles<dim>::declare_parameters()`: the `f_gravity` parsed function was only constructed in `parse_parameters()` but was already dereferenced earlier, in `declare_parameters()`. Giving `f_gravity` a default value (as part of the change above) fixes this. [#PR](link)
