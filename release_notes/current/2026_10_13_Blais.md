## [Master] - 2026/10/13

### Fixed

- MINOR Fixed several coding errors of the sharp immersed-boundary solver that do not change the results of existing cases. When particles are loaded from a file, the coupling is now detected from all the particles of the file instead of the first `number of particles` ones, and the inertia can be given as a 3 by 3 matrix in both 2D and 3D (in 2D this threw an exception). The `post_refinement` signal slot of the refinement control is now disconnected instead of accumulating at every time step, the end of simulation post-processing is no longer skipped when `calculate force` is false, the pressure reference inside the particles accounts for the pressure scaling factor, and the unsupported parameter combinations (non-constant density, non-Newtonian fluid with lubrication force) are now also detected in Release.
