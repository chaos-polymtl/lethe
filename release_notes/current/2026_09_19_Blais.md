## [Master] - 2026/09/19

### Fixed

- MINOR `Visualization::print_intermediate_format` serialized cross-rank printing with a `usleep`/`MPI_Barrier` round-robin and wrote directly to raw `std::cout`. `MPI_Barrier` only synchronizes rank progress, not delivery of already-written stdout through the process launcher, so under CI load the per-rank blocks could be interleaved or reordered in the captured output, making `load_balancing_mobility_status.mpirun=2` and other mobility-status tests intermittently fail. Each rank now builds its output block as a string, gathers all blocks to rank 0, and rank 0 prints them in order through `pcout`, mirroring the pattern already used by `print_xyz`. [#PR](link)
