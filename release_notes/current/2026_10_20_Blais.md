## [Master] - 2026/10/20

### Documentation

- MINOR The mesh of the single particle sedimentation example (unresolved CFD-DEM) was coarsened from 20x40x20 to 15x30x15 cells, so that the particle diameter is now 75% of the cell size instead of being equal to it. The mesh and void fraction smoothing length study shown in the documentation of the example was redone with cell size to particle diameter ratios of 1.33, 1.82, 2.22 and 2.86. This study can now be regenerated using the new `parametric_study` folder of the example, which contains parameter file templates and scripts to generate, launch and plot the cases. The analytical solution of the post-processing script was moved to `single_particle_sedimentation_funcs.py` so that it is shared by both post-processing scripts, and the extraction of the particle position was fixed to work with recent versions of NumPy (2.5 and above).
