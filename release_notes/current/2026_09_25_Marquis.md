## [Master] - 2026/09/25

### Added

- MAJOR The walls of the grid can now be isothermal in multiphysic DEM (`solver type = dem_mp`), in both `lethe-particles` and the CFD-DEM solvers (`lethe-fluid-particles` and `lethe-fluid-particles-matrix-free`). Each DEM boundary condition has a new `thermal boundary type` parameter (`adiabatic`, the default, or `isothermal`) and a new `wall temperature` subsection in which the temperature of the wall is given as a function of space and time. The function is evaluated at each particle-wall contact point, so the temperature of a wall can be non-uniform. [#PR](https://github.com/chaos-polymtl/lethe/pull/PR)
