## [Master] - 2026/07/27

### Changed

- MINOR Fixed the compilation warnings introduced by the deal.II 9.8 release. The deprecated `MGTransferGlobalCoarsening<dim, VectorType>` alias used by the matrix-free solvers (`lethe-fluid-matrix-free` and `lethe-fluid-particles-matrix-free`) now resolves to `MGTransferMatrixFree<dim, Number>`, into which it was merged upstream, when building against deal.II 9.8 or newer; a `DEAL_II_VERSION_GTE(9, 8, 0)` guard keeps the old `MGTransferGlobalCoarsening` name for deal.II 9.7, so backward compatibility is preserved. The implicit `double`-to-`unsigned int` conversions in `insertion_volume.cc` are made explicit (redundant `floor` calls on integer division removed, and the point-count truncation wrapped in a `static_cast`). The deal.II-internal `-Wdeprecated-declarations` warning triggered when instantiating `SparseMatrixTools::restrict_to_full_matrices` (which still relies on the deprecated `ConsensusAlgorithms::Process` class internally) is suppressed locally at the call site until it is resolved upstream. Finally, the matrix-free prototypes (`matrix_free_advection_diffusion`, `matrix_free_navier_stokes`, `matrix_free_stokes` and `matrix_free_mortar_poisson_consistent_integration`) are updated for the deprecated two-argument `TrilinosWrappers::SparsityPattern` constructor and `reinit` (now passing the number of entries per row) and the deprecated `MGTransferGlobalCoarsening` name (guarded the same way as the solvers).
