## [Master] - 2026/09/14

### Fixed

- MAJOR The matrix-based (`lethe-fluid`, `lethe-fluid-vans`, `lethe-fluid-nitsche`, `lethe-fluid-sharp`, `lethe-fluid-particles`) and matrix-free (`lethe-fluid-matrix-free`, `lethe-fluid-vans-matrix-free`, `lethe-fluid-particles-matrix-free`) solvers now report the actual reason a linear solve failed. The exception raised by `deal.II` was caught by reference and rethrown by value (`throw e;`), which sliced it to its `std::exception` base: the file, line and message were destroyed, along with `SolverControl::NoConvergence::last_step` and `last_residual`, and every failed run aborted with the single word `std::exception`. The handlers of `solve_system_GMRES`, `solve_L2_system` and `solve_system_BiCGStab` now rethrow the original exception and print the iteration and residual the solver stopped at, next to the tolerance it was aiming for. [#PR](link)
- MINOR The BiCGStab solvers now report whether the solve stopped short of its iteration budget. `deal.II` and Trilinos raise `SolverControl::NoConvergence` both for a genuine non-convergence and for an algorithmic breakdown, discarding the flag that tells them apart; comparing the last step against the maximum recovers the distinction, which matters because a breakdown is not fixed by a larger iteration budget or a higher preconditioner fill level. [#PR](link)
- MINOR An unsupported `preconditioner` is now reported as a configuration error instead of a solver failure. The `AssertThrow` that validates it was raised inside the try block of each linear solve, so the handler written for solver failures caught it: the matrix-based solvers rebuilt the preconditioner three times and reported `GMRES solver failed!` before stopping, and the matrix-free solvers silently ignored it when `force linear solver continuation` was set. [#PR](link)
- MINOR The `Solve linear system` timer section of the matrix-free solvers is now held by a `TimerOutput::Scope` so that it is closed on every path out of the solve, including the one taken when a failed linear solve rethrows. [#PR](link)
