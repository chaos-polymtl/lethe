## [Master] - 2026/10/21

### Fixed

- MINOR The heating stage of the 3D heated packed bed example (DEM-MP) was running with the time step of the checkpoint (2.5e-5 s) instead of the prescribed 1 s, since a restart now keeps the checkpointed time step unless `override time step on restart` is enabled. This parameter is now set to `true` in `heat-packed-bed.prm`. The output frequencies of the three stages were reduced to generate fewer vtu files, and the post-processing script now locates the end of the loading and flipping stages from the output times instead of hard-coded vtu indices, so that it no longer depends on the output frequency.
