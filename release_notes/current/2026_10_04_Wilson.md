## [Master] - 2026/10/04

### Fixed

- MINOR The state of the particle insertion object was not checkpointed in CFD-DEM simulations (`lethe-fluid-particles` and `lethe-fluid-particles-matrix-free`), as it already was in DEM simulations. When a CFD-DEM simulation was restarted while particles were still being inserted, the insertion object was reinitialized and the particles that had already been inserted before the checkpoint were inserted again. The insertion object is now written to the `.insertion_object` checkpoint file and read back when restarting. Checkpoints written before this change do not contain this file and can still be used to restart a simulation, in which case the insertion object keeps its initial state. [#PR](https://github.com/chaos-polymtl/lethe/pull/PR)
