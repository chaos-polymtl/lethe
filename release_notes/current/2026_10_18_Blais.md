## [Master] - 2026/10/18

### Fixed

- MAJOR The void fraction was never percolated at the end of a time step in `lethe-fluid-vans-matrix-free`, since the solver called `finish_time_step()` instead of `finish_time_step_fd()`. The time derivative of the void fraction was therefore always evaluated with respect to the initial void fraction. Only transient simulations with a void fraction that varies in time (e.g., a time-dependent void fraction function) and `void fraction time derivative = true` are affected. `lethe-fluid-particles-matrix-free` was not affected. [#](https://github.com/chaos-polymtl/lethe/pull/)
- MINOR The Jacobian of the matrix-free VANS operator read the hessians of the trial functions when `enable hessians in residual` was true, but only evaluated them when `enable hessians in jacobian` was true. The multigrid level operators are always built with the hessians enabled in the residual, so setting `mg enable hessians in jacobian = false` made the level operators read hessians that were never evaluated (an assertion in debug, undefined values in release). The hessians are now read only when they are evaluated. This only affects the preconditioner, not the converged solution. [#](https://github.com/chaos-polymtl/lethe/pull/)
