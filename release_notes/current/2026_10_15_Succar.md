## [Master] - 2026/10/15

### Added

- MINOR Added the possibility to output the quadrature points with the QCM filter diameter and the associated cell index when QCM is used in CFD-DEM, at the first iteration. This can be done by setting ``output qcm`` to ``true`` in the ``void fraction`` subsection. When this is activated, the cell index field is also output in out.pvs. Using these files along with out.pvd allows visualizing the QCM filters and verifying their coverage of a given cell.This feature works for the ``lethe-fluid-particles`` and ``lethe-fluid-particles-matrix-free``.
