## [Master] - 2026/07/31

### Added

- MINOR This PR adds two parameters for the simulation control: end control, of type Patterns::Selection with options iteration and time, and iteration end, of type Patterns::Integer. This allows to set a maximum number of iterations for transient simulations, whereas previously only a maximum simulation time value was available. This is useful for transient simulations with a challenging initial condition, where we use a strategy of running the *N* first iterations with a robust (and expensive) solver configuration, then checkpointing and restarting with a cheaper configuration. The default end control is time, which preserves the previous behavior. When the end control is set to iteration, the end time is fully ignored, including for the calculation of the last time step.
