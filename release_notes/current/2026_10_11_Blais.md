## [Master] - 2026/10/11

### Changed

- MINOR This PR reduces the time it takes to link Lethe. The applications and the unit tests are now linked with mold or lld when one of them is installed and neither deal.II nor the user selected a linker already. deal.II only selects these linkers if they were installed when deal.II itself was configured; otherwise the default GNU linker (ld) was used, which is about ten times slower on the Lethe executables in Debug. The new CMake option `LETHE_USE_FAST_LINKER` (ON by default) disables this behavior. [#2155](https://github.com/chaos-polymtl/lethe/pull/2155)

- MINOR This PR splits the explicit instantiations of `ParticleParticleContactForce` and `ParticleWallContactForce`, which were the two longest files to compile, over one source file per dimension (`_2d.cc` and `_3d.cc`) so that they are compiled in parallel. The definitions of their member functions are moved to `particle_particle_contact_force.templates.h` and `particle_wall_contact_force.templates.h`; only the namespace qualification of a few names changes. The results are unchanged. [#2155](https://github.com/chaos-polymtl/lethe/pull/2155)
