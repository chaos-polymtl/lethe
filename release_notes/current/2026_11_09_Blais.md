## [Master] - 2026/11/09

### Fixed

- MINOR This PR fixes the restart of the dynamic flow control. Its checkpoint file stored the previous beta force and average velocity with only 6 significant digits. The main controller multiplies the error on the average velocity by alpha divided by the time step, so a restarted simulation applied a different beta force than the uninterrupted simulation. The checkpoint is now written with enough digits to be read back exactly, and its reading fails with a clear message when the file is truncated. An out-of-range `flow direction` (for example `2` in 2D, or a negative value) is now rejected. Before, it wrote the beta force out of the bounds of its tensor in Release mode. The `flow direction`, `inlet boundary id`, `alpha` and `beta threshold` entries now have restricted ranges. The flow controller was also cleaned up, with no change in the results: complete Doxygen documentation, `const` accessors, private controllers, named constants and descriptive member names.
