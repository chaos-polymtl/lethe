## [Master] - 2026/10/14

### Added

- MINOR The new `contrib/validation/compare_validation_runs.py` script, called at the end of `validate_lethe.sh`, compares the data files of every validation case with those of the two previous runs. It flags the cases whose results changed, which produced no data or plot, or whose wall time changed by more than 5%, and names every changed data file with its maximal relative change. It writes a report in the run folder, with the diffs of the changed files in `comparison_diffs/`. When `LETHE_VALIDATION_SLACK_WEBHOOK` is set, it posts to Slack a summary of every case, with its previous and current wall time and a legend of the symbols, followed by one message per case that changed or failed, which shows the beginning of the diff of every changed file or the end of the Slurm log of the case. The rotating drum validation now also stores its velocity profiles, and every validation case removes the outputs of a previous run before running its simulation, so that a failed simulation or post-processing cannot go unnoticed. The results of the cylindrical gas-solid fluidized bed validation are now stored in a folder named after its example, `gas-solid-fluidized-cylinder-bed`. [#PR](link)

### Fixed
