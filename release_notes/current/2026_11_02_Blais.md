## [Master] - 2026/11/02

### Fixed

- MINOR The axis labels of the Jurin's law post-processing script used `\text{}` (`$t \text{[s]}$`, `$\Delta H \text{[mm]}$`). In validation mode the script does not use LaTeX, so matplotlib's mathtext draws the labels, and the mathtext in matplotlib 3.6 on the validation machine (Ubuntu 24.04) cannot parse `\text`, which crashed the script before the figure was saved. The labels are now `$t$ [s]` and `$\Delta H$ [mm]`, which work with both mathtext and LaTeX. The plotted data and the validation `.dat` files are unchanged.
