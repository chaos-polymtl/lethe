## [Master] - 2026/10/30

### Added

- MAJOR Lethe can now optionally be linked with the [QMOMKit](https://github.com/polycfd/QMOMKit) library (version 1.x), which provides quadrature-based methods of moments, by configuring it with `-DLETHE_WITH_QMOMKIT=ON` and, if QMOMKit is not installed in a standard location, `-DQMOMKIT_DIR=/path/to/qmomkit/installation`. QMOMKit is linked with the solvers library and the `LETHE_WITH_QMOMKIT` preprocessor macro is defined. Without the option, Lethe neither looks for nor requires QMOMKit. The new unit test `solvers/qmomkit_phase_space_evolution_01`, adapted from a QMOMKit verification test, runs a complete QMOM case (moment inversion and phase-space evolution compared against a closed-form solution) and only runs when Lethe is linked with QMOMKit. A new continuous integration job, `CI-Lethe-with-QMOMKit`, compiles Lethe with QMOMKit and runs the tests of the coupling, whose names start with `qmomkit_`.
