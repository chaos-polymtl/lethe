## [Master] - 2026/10/06

### Deprecated

- MAJOR The enum parameters whose accepted strings differed from the enumerator names now take the enumerator name as value. The previous values are deprecated: they remain accepted, but print a warning naming the value to use instead. The deprecated values and their replacements are: `extra verbose` -> `extra_verbose` (all `verbosity` parameters); `fluid 0`/`fluid 1` -> `fluid_0`/`fluid_1` (`monitored fluid`, `monitored fluid with phase change`, `postprocessed fluid`, `viscous dissipative fluid`, `Carman-Kozeny fluid with phase change`); `multiple step bdf`/`initial solution` -> `multiple_step_bdf`/`initial_solution` (`bdf startup method`); `power-law` -> `powerlaw` (`rheological model`); `immersed solid tanh`/`immersed solid gaussian` -> `immersed_boundary_tanh`/`immersed_boundary_gaussian` (`tracer diffusivity model`, `tracer reaction constant model`); `fluid-fluid`/`fluid-solid` -> `fluid_fluid`/`fluid_solid` (material interaction `type`); `phase change` -> `phase_change` (`surface tension model`); `inverse diagonal`/`additive schwarz method` -> `inverse_diagonal`/`additive_schwarz_method` (`mg smoother preconditioner type`); `decrease by one`/`go to one` -> `decrease_by_one`/`go_to_one` (`mg p coarsening type`); `darcy phase change`/`carman-kozeny phase change` -> `darcy_phase_change`/`carman_kozeny_phase_change` (`permeability model`); `gauss-lobatto` -> `gauss_lobatto` (void fraction `quadrature rule`); `implicit`/`semi-implicit`/`explicit` -> `fully_implicit`/`semi_implicit`/`fully_explicit` (`drag coupling`); `number of iterations`/`fraction of rayleigh time` -> `fixed_number_of_iterations`/`fixed_fraction_of_rayleigh_time_step` (`dem iteration control`); `projection-based interface sharpening`/`pde-based interface reinitialization`/`geometric interface reinitialization` -> `projection_based_sharpening`/`pde_based`/`geometric` (interface reinitialization method `type`); `piecewise polynomial` -> `piecewise_polynomial` (`transformation type`); `electric field`/`magnetic field` -> `electric_field`/`magnetic_field` (`electromagnetic scaling type`); `number`/`volume` -> `number_based`/`volume_based` (`distribution weighting basis`); `function weak`/`partial slip`/`neumann traction` -> `function_weak`/`partial_slip`/`neumann_traction` (fluid dynamics boundary condition `type`); `convection-radiation-flux` -> `convection_radiation` (heat transfer boundary condition `type`); `silver muller`/`electric field`/`magnetic field`/`impedance boundary`/`waveguide port` -> `silver_muller`/`electric_field`/`magnetic_field`/`impedance_boundary`/`waveguide_port` (time-harmonic Maxwell boundary condition `type`); `electric field`/`magnetic field`/`electromagnetic fields` -> `electric_field`/`magnetic_field`/`electromagnetic_fields` (mesh adaptation `variable`); `hyper rectangle`/`cylindrical tube`/`cylindrical helix`/`cut hollow sphere`/`death star` -> `hyper_rectangle`/`cylindrical_tube`/`cylindrical_helix`/`cut_hollow_sphere`/`death_star` (immersed boundary particle `type`). All the parameter files of the tests and of the examples, as well as the documentation, use the new values. [#2149](https://github.com/chaos-polymtl/lethe/pull/2149)

### Changed

- MINOR The default value, the accepted choices and the parsing of the parameters listed above are now derived from their enumeration with magic_enum. Three helpers are added to `core/utilities.h`: `enum_to_selection()` builds the `Patterns::Selection` string from the enumerators (optionally a subset of them) and from the deprecated strings of the parameter, an overload of `string_to_enum()` accepts these deprecated strings, and `warn_deprecated_parameter_value()` prints the deprecation warning on the first MPI process. This removes the remaining handwritten `to_string()` functions and string comparison chains from `parameters.cc`, `parameters_cfd_dem.cc`, `parameters_lagrangian.cc`, `parameters_multiphysics.cc` and `boundary_conditions.h`. The `Patterns::Selection` strings of the enum parameters converted in [#2138](https://github.com/chaos-polymtl/lethe/pull/2138) are generated by `enum_to_selection()` as well, instead of being written by hand; their accepted values are unchanged. The `*_resistance` aliases of the `rolling resistance torque method` use the same mechanism, which changes the wording of their deprecation warning. The enumerators of `LinearSolver::MultigridSmootherPreconditionerType` are renamed to `inverse_diagonal`, `additive_schwarz_method` and `chebyshev`. `Shape<dim>::ShapeType` becomes a scoped enumeration which covers all the shape types (`composite`, `rbf`, `opencascade`, `superquadric` and `plane`), and `ShapeGenerator` selects the shape from it; the previous shape names remain accepted in composite shape files and particle files. The boundary condition types of the tracer, CLS and Cahn-Hilliard physics, the laser `beam orientation` and `print parameters` are not affected. [#PR](link)

### Fixed

- MINOR The number of values given to the `error estimator`, `fraction coarsening` and `fraction refinement` parameters of the mesh adaptation is now checked against the number of `variable` in Release mode as well (`AssertThrow` instead of `Assert`); a mismatch used to be read out of bounds. The 3d-dam-break and cylinder-cooling examples, which gave a single `error estimator` for two variables, are corrected. The `ilu preconditioner fill` and `amg preconditioner ilu fill` parameters, which are read as integers, are now declared as non-negative integers instead of doubles, so that a fractional or negative fill is rejected when the parameter file is parsed. The `verbosity` of the `phase filtration` subsections of the CLS and Cahn-Hilliard physics only accepts `quiet` and `verbose`, as `extra_verbose` was never supported there.  [#2149](https://github.com/chaos-polymtl/lethe/pull/2149)
