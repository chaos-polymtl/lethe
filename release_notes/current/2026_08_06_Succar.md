## [Master] - 2026/08/06

### Fixed

- MAJOR The `expand particle-wall contact search` option in DEM allows the calculation of particle-wall overlaps with the boundary faces of the cell containing the particle, as well as with the boundary faces of neighboring cells. This is required for convex geometries. However, when this feature is used in a concave geometry, it can lead to the calculation of unphysical contacts. The issue particularly arises in domains that contain both convex and concave boundary regions. This PR addresses the problem by adding only the boundary faces of neighboring cells that form a convex boundary with the boundary face of the cell containing the particle. [#2079](https://github.com/chaos-polymtl/lethe/pull/2079)
