### Added

- MAJOR This PR adds a new grid generator for a cube mesh, which is a combination of an extruded plate with hole and a cylinder (both generated along the z axis). The input grid arguments are the cylinder radius, the half edge length of the plate, the height in z-direction and the number of subdivisions in z-direction.
