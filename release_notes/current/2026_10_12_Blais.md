## [Master] - 2026/10/12

### Changed

- MINOR The `run_clang_tidy.sh` script now builds the Lethe libraries using all the cores available on the machine (`nproc`) instead of a hard-coded 12 cores. [#2156](https://github.com/chaos-polymtl/lethe/pull/2156)

- MINOR The `lethe-parameter-check` executable now also parses the parameters after reading the parameter file, following the same sequence as the solvers (`declare()`, `parse_input()`, `parse()`). It consequently reports the errors and the warnings which are only raised when the parameters are parsed, such as the inconsistencies between the parameters of different subsections and the use of deprecated parameter values. The `check_parameter_files_in_examples.sh` script, which is used by the continuous integration to check the parameter files of the examples, monitors the output of `lethe-parameter-check` and now fails when a parameter file uses a deprecated parameter or a deprecated parameter value. [#2157](https://github.com/chaos-polymtl/lethe/pull/2157)
