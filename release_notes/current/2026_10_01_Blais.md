## [Master] - 2026/10/01

### Added

- MINOR This PR adds a `step` manifold type, which attaches a CAD manifold read from a STEP file to the boundaries of the mesh, in the same way as the existing `iges` manifold type. It also adds the `cad scale factor` parameter (default `1e-3`, the previously hard-coded value) to the `manifolds` subsection, so that CAD manifolds can be used with meshes that are not in meters.
