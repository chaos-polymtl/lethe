## [Master] - 2026/09/16

### Fixed

- MINOR The two-way coupled CFD-DEM solvers (`lethe-fluid-particles` and `lethe-fluid-particles-matrix-free`) hardcoded the `restart` flag to `true` when reading the mesh, causing `apply_initial_refinement` to always skip global mesh refinement. As a result, if the mesh is not read from a dem simulation, it would not be refined. The flag now reflects the actual `restart`/`read dem` state, matching the pattern already used in the one-way coupled VANS solvers. When no DEM simulation is read, the mesh can now be refined in the cfd-dem simulation. [#2128](https://github.com/chaos-polymtl/lethe/pull/2128)
