## [Master] - 2026/08/11

### Fixed

- MINOR Fixed a race condition in the unit test suite that made the CI fail intermittently with a linker error (`mold: fatal: ...cc.o: unknown file type`). Unit tests that had both a serial `.output` and a `.mpirun=N.output` golden file shared a single executable target, but only the `mpirun` variant was given the `test_dependency/....executable` fixture by deal.II. The serial variant could therefore be launched by `ctest -j` at the same time as the fixture test, and the two concurrent `ninja` invocations clobbered the same object file. The serial golden files of these tests were renamed to `.mpirun=1.output` so that every variant depends on the shared build fixture. [#2091](https://github.com/chaos-polymtl/lethe/pull/2091)
