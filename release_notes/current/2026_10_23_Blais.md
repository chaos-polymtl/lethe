## [Master] - 2026/10/23

### Fixed

- MINOR The post-processing scripts of the 3D heated packed bed (DEM-MP) and Jurin's law examples failed on the validation machine, which runs older Python packages (Ubuntu 24.04), so neither validation case produced data. The heated packed bed script used `Legend.legend_handles`, which requires matplotlib ≥ 3.7; it now builds its legend from proxy artists. The Jurin's law script passed pyvista arrays directly to `pd.DataFrame`, which fails when the array carries a name; they are now converted to plain numpy arrays first. The validation script of the heated packed bed now removes the whole `output` folder, since `rm -f output/out*` exceeded the argument list limit on 128 cores. [#2183](https://github.com/chaos-polymtl/lethe/pull/2183)
