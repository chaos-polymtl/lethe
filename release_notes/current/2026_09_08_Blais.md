## [Master] - 2026/09/08

### Added

- MAJOR This PR adds a built-in Rushton mixer grid generator (`set type = lethe` with `set grid type = rushton_rotor` or `rushton_stator`), which produces the rotating and the fixed halves of a baffled stirred tank agitated by a Rushton turbine from a single set of dimensions, together with a three-dimensional example of that mixer solved with the mortar element method, in both a matrix-based and a matrix-free version. Lethe grids are now also accepted for the rotor and stator meshes of a mortar simulation, which previously supported only `dealii` and `gmsh` meshes. [#PR](link)
