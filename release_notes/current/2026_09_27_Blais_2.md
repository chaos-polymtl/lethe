## [Master] - 2026/09/27

### Changed

- MAJOR Lethe now requires deal.II to be compiled with magic_enum support (`DEAL_II_WITH_MAGIC_ENUM=ON`). Configuring Lethe against a deal.II installation without it now stops with an error explaining how to enable it. The deal.II Ubuntu packages and the `dealii/dealii` Docker images already provide it; installations built with candi or by hand may need to install magic_enum and reconfigure deal.II. The release CI now also tests deal.II 9.8.0, and the Lethe Docker image, the clang-tidy image recipe and the installation documentation now target deal.II 9.8.0. [#PR](link)
