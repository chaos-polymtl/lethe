## [Master] - 2026/09/27

### Changed

- MAJOR Lethe now requires deal.II to be compiled with magic_enum support (`DEAL_II_WITH_MAGIC_ENUM=ON`). Configuring Lethe against a deal.II installation without it now stops with an error explaining how to enable it. deal.II 9.8 and newer ship a bundled copy of magic_enum and enable it by default, and the deal.II 9.7.1 Ubuntu packages and the `dealii/dealii` Docker images also provide it; only a deal.II 9.7 installation compiled from source may need a separate installation of magic_enum. The release CI now also tests deal.II 9.8.0, and the Lethe Docker image is now built from deal.II 9.8.0. [#PR](link)

### Documentation

- MINOR The Windows (WSL) installation guide was modernized. It now installs Ubuntu 24.04 with `wsl --install`, installs deal.II 9.7.1 from the backports PPA, and its candi instructions were updated: p4est 2.3.6 is selected, and the obsolete Trilinos downgrade and compiler steps were removed. The Lethe installation steps were also fixed: the source folder is consistent between the installation and update instructions, Lethe is installed with `make install` and added to the `PATH`, and `numdiff` is installed with the other packages. The candi instructions of the Linux and Apple ARM guides now explain how to select p4est 2.3.6 and no longer refer to line numbers of `candi.cfg`. [#PR](link)
