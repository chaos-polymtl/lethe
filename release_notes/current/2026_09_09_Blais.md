## [Master] - 2026/09/09

### Fixed

- MAJOR This PR implements the `pressure scaling factor` parameter in the matrix-free Navier-Stokes solver. The matrix-free operators never rescaled the pressure unknown, but the pressure degrees of freedom of the Newton correction were still rescaled at the end of the linear solve, so setting the parameter with `lethe-fluid-matrix-free` silently produced a wrong Newton correction. The factor is now applied by the operator itself, consistently in `vmult()`, in the inverse diagonal used by the smoothers and in the assembled matrix used by the additive Schwarz smoother, by the coarse-grid solvers and by the fine-level ILU and direct solvers, with the same factor on every multigrid level. [#PR](link)

### Documentation

- MINOR This PR corrects the description of the `pressure scaling factor` parameter. The documentation stated that the inverse of the factor is applied to the pressure after solving, whereas the code rescales the pressure unknown the linear solver works with and applies the factor back to the Newton correction. [#PR](link)
