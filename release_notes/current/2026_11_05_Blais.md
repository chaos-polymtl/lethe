## [Master] - 2026/11/05

### Documentation

- MINOR This PR adds a coding standards page to the Contributing section of the documentation. It describes the naming conventions for variables, functions, classes and types, the need for defensive programming, when to use `Assert` (in loops and performance-critical sections) and `AssertThrow` (everywhere else and for every error a user can trigger), and the use of smart pointers instead of raw `new` and `delete`. The checklist of every pull request template now asks the author to confirm that the coding standards were followed, with a link to this page. [#PR](link)
