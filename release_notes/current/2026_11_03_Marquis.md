## [Master] - 2026/11/03

### Fixed

- MINOR Claude found that the incident fields of the waveguide ports of the time-harmonic Maxwell solver did not form a wave entering the domain for TE modes when the cross product of the transverse directions defined by the corners pointed outward, and for TM modes when it pointed inward, which resulted in a vanishing excitation. Also, the magnetic field of the TM modes had the wrong sign with the exp(-i omega t) convention. This PR fix this, and change existing parameter file to check all the possible configurations.
