## [Master] - 2026/10/13

### Added

- MINOR The void fraction is now available to the auxiliary physics through the `MultiphysicsInterface` when the fluid dynamics solver is a VANS or CFD-DEM solver (`lethe-fluid-vans`, `lethe-fluid-vans-matrix-free`, `lethe-fluid-particles` and `lethe-fluid-particles-matrix-free`). These solvers register the void fraction DoFHandler, mapping, present solution and previous solutions under `PhysicsID::void_fraction`, so that an auxiliary physics can read them with the usual getters (`get_dof_handler`, `get_mapping`, `get_solution` and `get_previous_solutions`). The void fraction is not an auxiliary physics: it is not added to the active physics, and requesting it throws an error when the fluid dynamics formulation is not VANS. [#2160](https://github.com/chaos-polymtl/lethe/pull/2160)

### Changed

- MINOR The DoFHandler, the present solution and the previous solutions of the void fraction in the `ParticleProjector` are now stored as shared pointers, as is done for the other physics, so that they can be shared with the `MultiphysicsInterface`. [#2160](https://github.com/chaos-polymtl/lethe/pull/2160)
