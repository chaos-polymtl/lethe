## [Master] - 2026/11/25

### Added

- MINOR `compare_validation_runs.py` shares the validation report (`report.pdf`) in the Slack channel right after the summary, so that it can be read in Slack, when `LETHE_VALIDATION_SLACK_TOKEN` and `LETHE_VALIDATION_SLACK_CHANNEL` contain the token of a Slack bot with the `files:write` scope and the ID of the channel. Incoming webhooks cannot send files. [#2243](https://github.com/chaos-polymtl/lethe/pull/2243)

### Changed

- MINOR The report of the validation (`contrib/validation/validate_lethe.sh`) is assembled by the new script `generate_validation_report.py` instead of ImageMagick. It has a cover page, a clickable table of contents and bookmarks grouped by solver, and a title page before every case that lists its files and those that are missing. The plots are no longer rasterized: they remain vector graphics, scaled onto uniform pages under a header that names the case, and the report is about 15 times smaller. The validate.sh script of every case lists its plots with the new `add_to_report` function, the report is updated after every case, and the cases of `validation_cases*.txt` are grouped by solver, which is given in a third column. The validation now requires the Python package pypdf instead of ImageMagick. [#2243](https://github.com/chaos-polymtl/lethe/pull/2243)

### Fixed

- MINOR `validate_lethe.sh` used `contrib/validation/validation_cases.txt` at the root of the file system as default list of cases, since the path of Lethe was set after the default. [#2243](https://github.com/chaos-polymtl/lethe/pull/2243)
