## [Master] - 2026/11/18

### Changed

- MINOR clang-tidy now runs every `bugprone-*` check except a few noisy ones, whose exclusion is explained in `.clang-tidy`, as well as `google-readability-casting`, `misc-redundant-expression` and `misc-throw-by-value-catch-by-reference`. `bugprone-assert-side-effect` covers the assertions removed in Release (`Assert`, `AssertDimension`, `AssertIndexRange`, `AssertIsFinite` and `assert`). The CI script now validates `.clang-tidy` with `clang-tidy --verify-config`, so a misspelled check or option fails instead of being silently ignored. It also fails when `run-clang-tidy` fails without reporting a diagnostic, and no longer builds the libraries, since clang-tidy only needs `compile_commands.json`. The code changes that satisfy the new checks do not change any result. [#XXXX](https://github.com/chaos-polymtl/lethe/pull/XXXX)

### Fixed

- MINOR The periodic hills grid snapped `alpha` to 1 when it was within 1e-6 of 1 by converting it to an integer, which gave 0 for a value just below 1. It now sets `alpha` to 1, and the comparison uses `std::abs` instead of the unqualified `abs`. [#XXXX](https://github.com/chaos-polymtl/lethe/pull/XXXX)
