## [Master] - 2026/10/25

### Fixed

- MINOR The clang-tidy CI step never analyzed Lethe's headers. `run_clang_tidy.sh` passed `-header-filter "$SRC/include/*"`, but the headers are included as `source/<module>/../../include/...`, so the filter never matched them. The header filter is now set by `HeaderFilterRegex` in `.clang-tidy`, which matches both path forms and skips the bundled `include/ankerl/` library. As a result, class declarations, templates and inline code in `include/` are now checked. `performance-enum-size` and `modernize-avoid-c-style-cast` are disabled, as in deal.II. [#2185](https://github.com/chaos-polymtl/lethe/pull/2185)
