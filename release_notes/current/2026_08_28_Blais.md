## [Master] - 2026/08/28

### Changed

- MINOR Enabling the `fix boundary refinement` parameter of the `mesh adaptation` subsection without specifying any boundary ID in the `boundaries fixed` parameter was silently ignored. Since no boundary ID could be matched, the refine and coarsen flags of the boundary cells were never cleared and the boundary refinement obtained with `initial boundary refinement` was progressively coarsened away by the error estimator. Parsing this combination of parameters now throws an explicit error asking the user to fill `boundaries fixed`. [#2112](https://github.com/chaos-polymtl/lethe/pull/2112)
